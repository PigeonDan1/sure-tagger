Pipeline

从 ASR 样本到可检索标签

01

Manifest + Audio

读取每条样本的音频路径、transcript 和原始 metadata。

02

Language Layer

对 transcript 做确定性文本统计，音频语言始终由 FireRed LID 识别；输入为空时仅文本统计使用 speaker 路由 ASR，语言复用同一次 LID 证据。

03

Acoustic + Scene

提取时长、静音片段、SNR、DNSMOS、RT60、C50；AED 检出 speech/singing/music，DASS 输出背景噪音类别与分类组成。

04

Unified Tags

输出按 tag group 组织的 JSON；speaker 中文和英文使用 MOSS/FireRed，其他、混合或未知语言使用官方 DiariZen + Qwen3 ASR 链路。
