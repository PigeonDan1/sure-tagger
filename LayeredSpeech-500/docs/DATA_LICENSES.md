# Data and Asset Licenses

The release ships lock files and preparation instructions, not upstream audio.
Before downloading any asset, read the current upstream license and record the
accepted revision in a local manifest.

| Asset | Use | Release policy |
| --- | --- | --- |
| AMI | English reference prompts | External; retain upstream attribution and terms |
| AliMeeting | Mandarin reference prompts and meeting material | External; do not redistribute by default; CC-BY-NC terms apply where stated by upstream |
| AISHELL-3 | Mandarin reference prompts | External; retain upstream attribution and terms |
| FLEURS | Additional-language reference prompts | External; retain upstream attribution and terms |
| Measured RIR | Room acoustics | User supplied; no redistribution permission is granted here |
| Real music | Music-enabled scenes | User supplied; no redistribution permission is granted here |

The generated benchmark audio is not included in this code release because its
reference recordings and environmental inputs inherit upstream restrictions.
