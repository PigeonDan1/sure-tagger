## 2. η² 与 SηK 的含义

### 2.1 为什么要算 η²

聚类冻结后，需要验证“同一簇里的样本是否真的更相近”。这里的相近不是标签距离，而是模型在这些样本上的误差是否更接近。η² 是这个问题的主指标；它只做冻结后的诊断，不参与向量、选 K 或 cluster_id assignment。

设 e_i 是样本 i 的有效错误率（英语使用 WER，中文使用 CER），有效样本集合为 V，N=|V|。第 g 个簇的有效子集为 V_g，n_g=|V_g|，则：

~~~text
μ* = Σ(i∈V) e_i / N
μ_g = Σ(i∈V_g) e_i / n_g

SS_total   = Σ(i∈V) (e_i − μ*)²
SS_within  = Σ(g) Σ(i∈V_g) (e_i − μ_g)²
SS_between = Σ(g) n_g(μ_g − μ*)²
            = SS_total − SS_within

η² = SS_between / SS_total
   = 1 − SS_within / SS_total
~~~

直观解释：SS_total 是 1000 条误差相对全局均值有多散，SS_within 是改用各自簇均值后还剩多少散度，η² 是总散度中由簇间差异解释的比例。

- η²=0：分组没有让同簇样本更接近。
- η² 越高：同簇误差越集中、簇间均值差异越明显。
- 本次标签簇 η²=0.348：约 34.8% 的 Qwen 误差散度来自簇间差异；组内标准差与全局标准差之比为：

~~~text
ρ = σ_within / σ_total
  = √(1 − η²)
  = 0.807
~~~

也就是组内标准差约为全局的 80.7%。η² 不是分类准确率，也不是场景真实性证明。C04/C05 的参考极短且逐样本错误率中位数仍接近 100%，会明显贡献组间差异；因此 η² 必须和簇大小、有效样本数及画像一起读。

**小簇敏感性：**排除 C05 后，仍保留其余冻结标签，η²=0.294319（有效 n=962）；同时排除 C04 和 C05 后，η²=0.144454（有效 n=945）。因此主值 0.348 不能脱离 C04/C05 的总量（17/38 条）和现已齐全的有效诊断 n（17/38 条）单独解读。

### 2.2 为什么还要算 SηK

只最大化 η² 会鼓励不断增加簇数：簇越多，组内自然越容易变得相似。SηK 用一个透明的 K 复杂度代价约束这种倾向：

~~~text
SηK = η² − λ · log₂( max(K, K_ref) / K_ref )
λ = 0.3，K_ref = 6
~~~

当 K≤6 时代价为 0；K=10 时代价为 0.3·log₂(10/6)=0.221090。因此 SηK 回答的是“增加这些类别是否值得”，而不是“这个样本属于哪个簇”。它是方案比较的 post-hoc 指标，不会反向修改冻结分区。

### 2.3 四个对照怎么读

- **随机：** 固定当前 6 个簇的样本数，随机打乱标签 80 次，η² 取均值 0.005415。它是无结构基线。
- **当前标签：** 用冻结的 tags-only C00–C05，η²=0.348366，SηK=0.348366。
- **按数据源：** 10 个有有效 Qwen 分数的来源各成一组，η²=0.587366；K=10 的代价为 0.221090，SηK=0.366276。它是对照，不是要发布的场景分区。
- **最优 6 段：** 将 1000 个错误率排序后切成 6 段，η²=SηK=0.980032。它是按模型难度切桶的上界，不是标签驱动的场景方案。

## 3. 为什么要做这次聚类

这次工作的目标不是回答“哪个数据源更难”，也不是把 WER/CER 切成几档，而是建立一套所有 ASR 都能共用的场景分桶。它需要同时满足三个条件：

1. **可解释：** 每个簇能用标签画像说明其声学、时长、音乐/噪声和说话人结构。
2. **可复用：** 同一条 cluster_id 能用于 Qwen、Whisper、SenseVoice 等模型，不因更换模型而改变场景定义。
3. **可验证：** 冻结后可以用 η²/SηK 检查误差是否在簇内更相近，以及这种收益是否值得六个簇的复杂度。

因此，向量、距离和聚类是手段；最终产物是可审计、可复用的 cluster_id，不是一串孤立的专业术语。

## 4. 为什么需要向量与距离

### 4.1 每条音频的 23 维向量

原始标签是混合数据：有连续数值、二值状态、集合和缺失值。把每条音频写成固定的 mixed vector，才能复现“为什么两条样本相似”。本次向量由 15 个数值、5 个二值和 3 个集合特征组成，并保存同维 missing mask。

| 轴 | 向量内容 | 为什么需要 |
| --- | --- | --- |
| content | 二值 music_present；集合 speech_music_events、external_noise_type、noise_detail | 区分音乐、语音事件和外部噪声构成 |
| interaction | 数值 speaker_count、overlap_ratio、speaker_change_count、speaker_change_rate_per_min；二值 speaker_overlap、multi_speaker、speaker_change、speaker_present | 描述多人、重叠和换说话人结构 |
| quality | 数值 nonspeech_ratio、snr_db、dnsmos_ovrl、dnsmos_bak、dnsmos_sig、dnsmos_p808 | 描述信噪比、非语音和质量 |
| spatial | 数值 duration_sec、silence_segment_count、silence_total_sec、rt60_sec、c50_db | 描述片段长度、静音和混响/清晰度 |

### 4.2 每个坐标如何变成可比较的差异

对数值特征 r，先在全体样本的有限值上计算中心和尺度：

~~~text
m_r = median({x_ir : x_ir finite})
s_r = IQR(x_·r)
~~~

如果 IQR 退化，依次使用 1.4826·MAD，再使用 1.4826·σ_pop；仍无散度时该坐标标记为 constant，不产生 observed 差异。标准化为：

~~~text
z_ir = (x_ir − m_r) / s_r
~~~

同一坐标 r 上的两个样本 i,j 的数值差异为：

~~~text
δ_num(i,j;r) = min( |z_ir − z_jr| / τ_num, 1 )
τ_num = 3
~~~

二值坐标只比较是否不同：

~~~text
δ_bin(i,j;r) = 1[v_ir ≠ v_jr]
~~~

集合坐标使用 Jaccard 差异：

~~~text
δ_set(i,j;r) = 1 − |A_ir ∩ A_jr| / |A_ir ∪ A_jr|
~~~

当集合并集为空时按实现记为 0。以上 observed 项只在双方都有值时计算；缺失不填 0。数值/二值坐标的缺失模式项为：

~~~text
m_f(i,j;r) = 1[missing_ir ≠ missing_jr]
~~~

集合坐标任一侧缺失时直接记 missing=1（包括双方都缺失的集合实现）。对一个轴，先分别求可比较坐标的 observed 平均值和 missing 平均值：

~~~text
d_axis(i,j) = 0.85·observed_axis(i,j)
              + 0.15·missing_axis(i,j)
~~~

最后对可计算的四个轴等权平均：

~~~text
d_tag(i,j) = mean{ d_axis(i,j) :
                    axis ∈ {content, interaction, quality, spatial},
                    d_axis ≠ None }
~~~

这样做的目的分别是：median/IQR 防止极端 SNR 或超长录音支配距离；截断阈值防止单一坐标支配距离；四轴等权防止字段多的一轴支配距离；显式 missing mask 保留“未知”这一事实。d_tag 是标签空间的差异，不是 ASR 误差。

## 5. 如何得到最终 6 类

### 5.1 从标签到冻结 cluster_id

1. **对齐：** 按 global_index 对齐 1000 条样本，读取四个标签轴。
2. **编码：** 形成 15 numeric + 5 binary + 3 set 的 23 维向量和 missing mask。
3. **计算距离：** 对所有可比较样本对计算 d_tag。
4. **搜索候选：** 在 K=6…12 上运行 k-medoids（seeds=0,1,2）和 average-linkage。
5. **候选选择：** 只在 K≥6 且 C_tag 可计算的候选中，用 J 比较标签空间紧度、来源稳定性和复杂度；WER/CER、η²、SηK 均不参与 assignment。
6. **细化并冻结：** 对候选进行 tag-only split/merge，合并标签画像不可区分的子簇，保留真实的 C04=17 小簇，最后 canonicalize 为 C00–C05。

### 5.2 k-medoids 具体做什么

给定 K 和距离矩阵，k-medoids 只把真实样本作为中心：

1. 用固定 seed 的 D² 规则初始化 K 个 medoid。
2. 把每个样本分配给距离最近的 medoid。
3. 在每个簇内选择使到其他簇内样本距离和最小的真实样本：

~~~text
m_g = argmin(r∈g) Σ(i∈g) d_tag(i,r)
~~~

4. 反复执行分配和更新，直到分配不再变化或达到迭代上限；比较多个 seed 和 average-linkage 候选。

初选结果是 k-medoids K=7：J≈0.214754、C_tag≈0.065147、Q_tag≈0.617333。tag-only merge 后冻结为 K=6：

~~~text
J       = 0.1947301463
C_tag   = 0.0705319843
Q_tag   = 0.6064
cut_tag = 0.0314741875
~~~

### 5.3 选择指标各自回答什么

C_tag 是簇内紧度，定义为按簇大小加权的簇内 medoid 距离中位数，越低越紧：

~~~text
C_tag = Σ(g) [ n_g · median(i∈g) d_tag(i,m_g) ] / N
~~~

Q_tag 是来源留一后的可复用性。令 a_s 为把来源 s 留出后、用冻结 medoid 识别该来源样本的准确率：

~~~text
q_raw = mean(s) a_s
Q_tag = clip( (q_raw − 1/K) / (1 − 1/K), 0, 1 )
~~~

J 是候选方案的综合代价，越低越好：

~~~text
J = λ_t·C_tag + λ_a·b_anchor
    + λ_k·ln(1+K)/ln(1+K_max)
    + λ_b·b_small + λ_r·b_non-main

b_anchor   = a_unanchored + max(0, q_min − Q_tag)
b_small    = Σ(g) max(0, n_min − n_g) / N_main
b_non-main = n_non-main / N

a_unanchored = n(没有稳定标签锚点的已分配样本) / N_main
n_main       = Σ(g) n_g，n_non-main = N − n_main
~~~

本次系数为 λ_t=1、λ_a=0.8、λ_k=0.15、λ_b=0.8、λ_r=0.8，K_max=12，n_min=30，q_min=0.12（最低来源留一复用阈值）。b_anchor 是缺少稳定标签锚点或 Q_tag 不足的惩罚；b_small 是小簇（小于 n_min）还差多少样本的比例；b_non-main 是未进入主簇的样本比例。本次冻结结果中 b_anchor=b_non-main=0。

cut_tag 是独立的局部结构诊断，不进入 J：先取每个样本的 k_graph 个近邻，只保留互为近邻的边 E，令 σ 为这些边距离的中位数，则

~~~text
w_ij = exp(−(d_tag(i,j) / σ)²)
cut_tag = Σ((i,j)∈E) w_ij · 1[cluster_i ≠ cluster_j]
          / Σ((i,j)∈E) w_ij
~~~

cut_tag=0.031474 表示局部相似边中只有约 3.15% 的加权连接跨越簇边界；越低表示越少切断局部相似样本。

这些指标只用于标签空间候选比较；η²/SηK 是冻结后的独立验证，不能混成一个“总准确率”。

## 7. 冻结后的独立诊断

### 7.1 七个模型的六类聚合 WER/CER

~~~text
cluster_error(m, c)
  = Σ(i∈V_m,c) [sub_i + ins_i + del_i]
~~~

其中 `all_i` 在 WER 样本上是参考单词数，在 CER 样本上是参考字符数；每条样本采用其 sidecar 中已经确定的 `metric_name`。表中数值均为百分比。

### 7.3 缺失和短参考的处理

- Whisper、SenseVoice 的 100 条泰语仍无有效 sidecar 误差，不进入这两模型的中位数、η² 或 SηK。Qwen 已用后续 1000 条推理补齐这 100 条泰语 CER，因此 7.1 与 7.2 的 Qwen 诊断均为 n=1000；fun-asr 本来就覆盖这 100 条。
- Qwen 的 C01/C05 现已覆盖整簇（122/38 条）。C05 逐样本中位数仍为 100%，因为 21 条极短参考饱和；7.1 的 micro WER/CER 则因 17 条泰语降到 17.26%，两种口径不要混读。
- C04/C05 的参考极短，100% 中位错误率可能是短参考饱和效应。发布 ASR 主表时，建议单独报告或剔除这两类。

## 8. 限制、使用与复现

### 8.1 可以说明什么、不能说明什么

可以用冻结的 C00–C05 做跨模型、跨版本的共同评测分桶，并同时报告簇大小、有效 n、画像和 η²/SηK。不能把簇名当地点真值，不能为每个模型按 WER/CER 重聚类，也不能把当前 η² 当成因果结论。

当前独立录音组较少，报告采用 post-hoc partition，不能宣称跨来源泛化已经被严格证明。新增来源或新语言时，应重新检查标签覆盖、缺失模式和小簇稳定性。

### 8.2 输入、输出与复现

输入文件包括 tags.jsonl、index_map.jsonl 和 sampled-100-per-source/manifest.jsonl；输出主键是 scene-clusters/cluster_assignments.jsonl 中的 C00–C05。冻结快照的关键值为：

~~~text

C_tag   = 0.0705319843
Q_tag   = 0.6064
J       = 0.1947301463
cut_tag = 0.0314741875
~~~

复现命令：

~~~bash
cd /hpc_stor03/sjtu_home/weihan.chen/share/compare/dataset/multi-data
python3 cluster_scenes.py
python3 error_homogeneity.py
python3 render_cluster_report.py
~~~

前两条命令分别重算标签分区和冻结后的独立诊断，最后一条生成 HTML/PDF。复跑后以新生成 JSON 中的 cluster_id 和指标为准。

报告输入快照：scene-clusters/cluster_assignments.jsonl、scene-clusters/cluster_summary.json、scene-clusters/error_homogeneity.json、scene-clusters/run_metadata.json，以及 sampled-100-per-source/sample_wer_cer.jsonl。PDF 是 reader-first 的版式，公式只保留能解释决策的部分；WER/CER 的编辑距离细节属于 sidecar 评测协议，不在此重复展开。

## 9. captioner 标签对照

对 `sampled-100-per-source/tags_captioner.jsonl` 使用与第 4.1 节 / PDF 主实验相同的 tags-only 流程：四轴 `d_tag`、k-medoids 等 5 类算法、K∈[6,12]、事后 SηK 筛选、split/merge。快照在 `dataset/multi-data/result/scene-clusters-captioner/`。

captioner 抽取保留了说话人交互和噪声/事件，但 SNR、DNSMOS、RT60、C50 全部为 null，时长缺失率 94.6%。因此 quality/spatial 轴几乎不贡献距离。冻结结果仍是 k-medoids K=6（J=0.140，Q_tag=0.605，source_driven=false），与 sure-tagger 主分区 ARI 仅 0.036。

Qwen 有效 1000 条上：captioner 簇 η²=SηK=0.0222，随机 0.0055，来源分组 SηK=0.366，sure-tagger 主实验 0.348。fun-asr 的 captioner SηK=0.0344。标签簇几乎不解释 ASR 误差，不能替换 `result/scene-clusters/`。
