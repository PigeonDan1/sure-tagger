## FireRed 运行覆盖

7 个数据集均完成推理，`failed=0`、`missing=0`。空文本是模型的合法观测，不被
静默替换：SlideSpeech 4 条、WenetSpeech net 12 条、GigaSpeech 4 条，其余数据集
为 0 条。有效音频总时长约 102.3 小时，批量推理使用 FireRed runtime 的 PCM16、
16 kHz、mono 输入、`beam_size=3`、`float32`。除 GigaSpeech 外的 6 集使用单卡
RTX 4090；GigaSpeech 的恢复运行由 6 个 shard 分布在 `cuda:0`--`cuda:5`。数据集
记录的有效 RTF 约为 `0.0104`--`0.0378`，其中分布式 GigaSpeech 的 RTF 是 worker
compute 下界，不等同于端到端 wall-clock RTF。

## 对当前 speaker v2 路由的适用范围

本报告只比较历史 ASR 模型质量，不能决定当前路由，也不能证明当前 q4_k pack 与旧
Python runtime 数值等价。2026-08-31 的双模型并发、反向语言选择和 availability
补位 smoke 已废止，不再作为集成验证结果引用。

当前合同固定为：

- standalone FireRed LID 识别为 `zh`/`zh-*` 时只运行 MOSS；
- 其他、mixed、unknown 或 LID failure 只运行 OpenASR 0.1.40；
- OpenASR stdout FireRed text 提供 ASR，version-locked trace raw turns 提供 C/M/O/X；
- stdout 与 trace 独立校验，中文/非中文模型分支之间不补位；
- 当前链路必须使用新的 route、trace parser 和 failure-injection 测试，不能沿用本报告
  的旧 24/24、112/112 或 207/207 回归数字。
